# ذِكر 📿

تطبيق ويب تقدمي (PWA) بسيط وسريع لعد الأذكار والنقرات، مصمم ليعمل كتطبيق مستقل على هاتفك.

## ✨ المميزات
- **عداد نقرات ذكي:** انقر على المربع لزيادة العداد، واضغط مطولاً لتصفيره.
- **إدارة المربعات:** إضافة، تسمية، وحذف (بضغطة مطولة عند الصفر) مع رسائل تأكيد.
- **واجهة زجاجية حديثة (Glassmorphism):** تصميم أنيق مع ألوان عشوائية جذابة.
- **وضع ليلي/نهاري:** تبديل سلس بين المظهرين مع حفظ التفضيل.
- **يعمل بدون إنترنت (Offline):** بفضل Service Worker، التطبيق يفتح ويعمل حتى بدون شبكة.
- **حفظ محلي (Local Storage):** بياناتك وعداداتك محفوظة على جهازك ولا تضيع عند إغلاق التطبيق.

## 🚀 طريقة التثبيت على الأندرويد
1. افتح رابط التطبيق من متصفح **Google Chrome**.
2. اضغط على قائمة النقاط الثلاث (⋮) بالأعلى.
3. اختر **"إضافة إلى الشاشة الرئيسية"** أو **"تثبيت التطبيق"**.
4. استمتع بالتطبيق كأيقونة مستقلة على هاتفك!

## 🛠️ التقنيات المستخدمة
- HTML5 / CSS3 / Vanilla JavaScript
- Progressive Web App (PWA) Manifest & Service Worker
